How many good acquisitions each vendor's archive holds at each site, from each sensor. Set what good means, then pick a site to look closer.

Paul Montesano, PhD · NASA Goddard Space Flight Center; ESSIC · CSDA Multispectral Optical SME Group · paul.m.montesano@nasa.gov ·

Suggested use: use this archive tool as a first pass. Select a set of acquisitions that broadly fit quality requirements, download the CSV, request thumbnails of those acquisitions, then reduce to the final selection based on the thumbnail inspection. If thumbnails are georeferenced, it is more obvious whether an acquisition is clear over a precise AOI. To see where and when each constellation collects worldwide, month by month, use the Vendor archive density page.
